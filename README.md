🧮 Calculator

A simple and interactive calculator built using HTML, CSS, and JavaScript.
This project demonstrates basic front-end development concepts with a clean and responsive UI.

✨ Features

.➕ Basic arithmetic operations (Add, Subtract, Multiply, Divide)

.🎨 Clean and responsive design with CSS styling

.⚡ Real-time calculation updates using JavaScript

.🖱️ Button click support for user-friendly interaction

.📱 Works across devices (desktop & mobile)

🛠️ Tech Stack

.HTML5 – Calculator structure

.CSS3 – Styling & layout

.JavaScript – Logic and interactivity
